## 검증과 한계

2026-11-08 최종 검증에서 단위 테스트 275개, APK 빌드, Lint(오류 0개·경고 13개)를 통과했다. 휴대폰에서는 운행 0건의 예약 탭과 200% 글자 크기의 입력 화면을 확인했다. 정확한 실행 결과와 APK 해시는 [검증결과](../검증결과.md)에 기록한다. 회귀 테스트는 미확인 기어, 차량 기준값 저장 조건, 주소 저장 설정, 에너지 만료, 첫 예약 진입, 요청 승인 전·거절 후 폼 보존, 카드 취소·중복, 인증키·본문 길이·계정 소유권을 대상으로 한다.

이번 계정 보호는 한 설치의 보관 기록을 한 계정이 소유하는 방식이다. 다른 계정으로 기록을 넘기거나 같은 설치에서 여러 계정의 사본을 전환하는 기능은 만들지 않았다. 기존 기록을 자동 삭제하지 않는다. Google 계정 자체가 회사 직원 권한을 검증하는 서버 인증은 아니며, 차량 접근은 별도 페어링 권한으로 이루어진다.

최초 연결은 주소·6자리 연결 번호에 더해 차량 인증키 확인이 필요하다. QR 자동 입력은 후속 편의 개선 대상이다. 현재 입력이 늘어나는 부분은 최초 연결에 한정된다.

Pleos 에뮬레이터가 로딩 화면 이후 종료되어 차량 전체 동선과 새 인증키 페어링의 기기 간 검증은 미완료다. 실차 신호 누락·지연, 실제 Google 로그인, 실제 카드사 알림, 2만 건 기기 성능, TalkBack 전체 동선, 제출용 release 서명·설치와 App Market 승인은 별도 검증 대상이다. 공식 공모전 기준 충족이나 심사 통과를 주장하지 않는다.
