# SHAREMATE

**차량이 스스로 쓰는 법인차 운행일지**

SHAREMATE는 법인 차량을 쓰는 회사의 운전자와 관리자를 위한 앱입니다. Hyundai Pleos(Android Automotive) 차량 앱이 기어·계기판·배터리·주소 같은 차량 신호로 운행일지를 직접 기록하고, 운전자는 주차 후 목적과 비용만 한 번에 확인합니다. 휴대폰 앱에서는 회사 차량을 고르고, 상태를 보고, 예약을 신청하고, 이달 운행·경비를 확인합니다.

### 실행 방법

1. Pleos Connect 에뮬레이터를 켭니다.
2. 차량용 APK를 설치합니다.

```bash
adb install apk/SHAREMATE-car-v2.15.0-release.apk
```

3. 하단 막대의 앱 목록(격자 아이콘)을 열고 **앱** 탭에서 **SHAREMATE**를 누릅니다. 처음에는 아래 화면이 열립니다. **시작 설정** 카드의 세 단계(법인·차량 정보 → 직원 등록 → 운전자 선택)를 누르면 해당 설정으로 가고, 직원을 등록하면 운전자 선택이 켜집니다.

<img src="docs/screenshots/car-first-run.jpg" alt="처음 실행한 차량 홈(밤): 머리줄의 다섯 탭, 운행 비서 검색 막대와 시연 체험 버튼, 인사말, 차량 정보·운행일지 확인·정보 내보내기 세 카드, 세 단계 타일이 있는 시작 설정 0/3 카드(운전자 선택은 직원 등록 전이라 꺼짐), 불 켜진 도시 위의 사고·특이사항 버튼 줄, 오른쪽 지금 열의 ‘등록된 직원이 없어요’와 직원 추가 버튼, 그 아래 예약·오늘 운행·이달 운행일지와 차량 그림이 있는 차량 타일" width="720">

4. 바로 둘러보려면 머리줄 오른쪽 끝, 검색 막대 옆의 **시연 체험**을 누릅니다. 여섯 단계로 운행 기록 흐름을 보여 주고, 실제 기록과 설정은 바꾸지 않습니다.
5. 직접 기록해 보려면 **설정 › 기록 › 시연 모드**를 켭니다. 홈 아래쪽, 사고·특이사항 버튼 줄 위에 **시연 출발 (D)** · **충전 시작** · **카드 승인** 버튼이 있는 시연 모드 줄이 생깁니다.
6. **시연 출발 (D)** 버튼을 누르고 잠시 뒤 **시연 주차 (P)** 버튼을 누르면, 운행이 기록되고 세 카드 아래에 **목적 확인** 카드가 나옵니다.

### 테스트 환경 및 필요한 설정

- **확인한 환경:** SHAREMATE가 설치되지 않은 Pleos Connect 에뮬레이터에 차량용 APK를 설치해 첫 실행, 시연 체험 여섯 단계, 시연 모드 운행 기록과 목적 확인까지 확인했습니다. 휴대폰용 APK는 SHAREMATE가 없는 Android 휴대폰 에뮬레이터(API 37)에 설치해 로그인, 처음 설정, 차량 연결 화면까지 확인했습니다. 호스트는 Windows 11, Android Emulator 37.2.12(`-gpu host`)입니다.
- **권한:** 따로 설정할 것이 없습니다. 차량 신호 권한은 설치할 때 함께 허용됩니다. 알림과 충전 상태 권한까지 미리 허용하려면 `adb install -g`로 설치합니다.
- **계정·서버:** 필요 없습니다. 기록은 차량 안에만 저장됩니다.
- **휴대폰 앱:** 휴대폰용 APK(`adb install apk/SHAREMATE-phone-v2.15.0-release.apk`)를 Android 9 이상 휴대폰에 설치합니다. 로그인 화면의 **시연 계정으로 둘러보기**로 Google 계정 없이 들어갑니다. 이 버튼은 디버그 빌드와, 제출한 APK처럼 Google 로그인 설정이 없는 빌드에 나옵니다.

### 더 해 보기

- **소스에서 빌드:** JDK 17로 `gradlew assembleCarRelease assemblePhoneRelease`를 실행하면 차량용과 휴대폰용 APK가 따로 나옵니다(디버그는 `assembleCarDebug` · `assemblePhoneDebug`). Android Studio에서 열어도 됩니다. release는 서명 키를 지정하지 않으면 서명되지 않은 APK가 됩니다.
- **차량에 다시 설치:** 차량 앱은 차량 사용자(Android user 10)로 실행됩니다. 덮어쓸 때는 `adb install -r --user 10 <APK 파일>`로 설치합니다.
- **Google 로그인:** Google Cloud에서 OAuth 클라이언트(Android, 웹)를 만들고, 웹 클라이언트 ID를 `local.properties`의 `sharemate.googleWebClientId`에 넣어 빌드합니다. ID가 없으면 Google 버튼이 꺼지고 이유가 화면에 나옵니다.
- **차량과 휴대폰 연결:** 차량의 설정 › 기록에서 **휴대폰 실시간 연동**을 켜면, 차량 탭의 휴대폰 연결 카드에 QR이 나옵니다. 같은 Wi-Fi나 핫스팟에서 휴대폰 앱의 **QR 찍어서 연결**로 찍으면 연결됩니다. 카드에 함께 나오는 주소·6자리 연결 번호·인증키를 직접 넣어도 됩니다.

## 차량에서

차량이 원본입니다. 기록은 차량 안에 저장되고, 운전자는 정차한 뒤 필요한 것만 확인합니다.

- **자동 기록:** P에서 D·R·N으로 바꾸면 기록을 시작하고, 다시 P로 돌아오면 계기판 거리로 운행을 마칩니다.
- **머리줄:** 로고와 다섯 탭 옆의 남은 폭을 **운행 비서**(문장으로 기록을 돕는 기능) 검색 막대가 채웁니다. 막대를 누르면 운행 비서가 열립니다. 시각은 차량의 상태 표시줄에 나오므로 앱에는 시계가 없습니다.
- **한 화면 홈:** 기본 글꼴의 전체 창에서 홈은 스크롤 없이 한 화면이고, 위에서 아래로 빈 곳 없이 쌓입니다. 맨 위에 인사말과 상태 한 줄이 있고, 바로 아래에 아이콘이 있는 큰 카드 세 장(차량 정보 · 운행일지 확인 · 정보 내보내기)이 놓입니다. 그 아래에는 늘 카드가 한 장 있습니다. 사고 대응, 카드·충전 비용, 목적 확인, 월 마감, 차량 관리처럼 차량이 답을 기다리는 **확인할 일** 가운데 가장 급한 것입니다. 여러 건이면 제목 줄에 1/3 같은 순서와 화살표가 붙고, 상태 줄이 ‘확인할 일 3건 · 카드 확인 → 목적 확인 → 차량 관리’처럼 알려 줍니다. 확인할 일이 없으면 그 자리에 최근 운행 세 건이 놓이고, 줄을 누르면 그 운행이 열립니다. 맨 아래에는 사고·특이사항의 큰 버튼 네 개가 늘 같은 자리에 있고, 그 위 하늘에는 도시가 서 있습니다.
- **처음 실행:** 아무것도 등록하지 않은 차량에서는 그 카드 자리에 **시작 설정**이 나옵니다. 법인·차량 정보, 직원 등록, 운전자 선택 세 단계를 타일로 보여 주고, 타일을 누르면 해당 설정이 열립니다. 운전자 선택은 직원을 등록하면 켜지고, 끝낸 단계에는 등록한 내용과 ✓가 붙습니다.
- **운전하는 직원:** 넓은 창에서는 지금 열(페이지 오른쪽에 세로로 놓인 카드들) 맨 위의 사용자 카드가, 좁은 창에서는 머리줄의 칩이 운전자를 보여 줍니다. 직원이 두 명 이상이면 하루 한 번 ‘오늘도 … 님이 운전하나요?’라고 묻고, ‘네’나 ‘다른 직원’으로 답합니다. 평소에는 ‘바꾸기’나 칩을 눌러 직원 카드를 고르고, 잘못 골랐다면 바로 실행 취소합니다. 직원은 설정 › 직원에서 관리합니다. 운행 기록이 있는 직원은 지울 수 없어, 운행기록부의 ④ 사용자 칸이 비지 않습니다.
- **목적 확인:** 주차하면 세 카드 아래의 목적 확인 카드에서 출·퇴근 / 일반 업무 / 개인 중 하나를 누릅니다. 같은 도착지를 같은 목적으로 세 번 이상 기록했다면 다음부터 자동으로 채우고 ‘방금 운행’ 카드로 알려 줍니다.
- **카드 결제 자동 반영:** 휴대폰의 카드 승인 알림과 카드 명세서를 차량이 감지한 충전·주유·톨게이트·주차와 맞춰 비용을 붙입니다. 애매한 건만 카드 확인 카드로 한 번 묻습니다. 자동 반영은 모두 되돌릴 수 있습니다.
- **운행기록:** 넓은 창에서는 날짜별 목록 옆에 가장 최근 운행의 상세가 열려 있어, 목적·④ 사용자·비용·⑩ 비고를 바로 고칩니다. 이번 달에 운행이 없으면 운행이 있는 달로 열립니다. 비용은 금액 칸 아래의 최근 금액과 +1,000 · +5,000 · +10,000 버튼으로 키보드 없이 넣을 수 있습니다.
- **빈 화면 대신 다음 할 일:** 운행이 없는 달이나 처음 설치한 차량에서는 빈 목록 대신 큰 카드 세 장(D로 출발 → P로 주차 → 목적 확인)과 운행이 있는 달로 가는 줄을 보여 줍니다.
- **월 마감과 Excel:** 목적·사용자·카드 확인이 끝나면 그 달을 마감하고, 운행기록부·직원별 현황·경비원장·차량관리·확인사항 5개 시트의 Excel을 저장합니다. 지난 달이나 지난 해로 넘겨 다시 저장하거나 마감을 풀 수도 있습니다. 검토 탭은 남은 확인 항목을 종류별로 보여 주고, 누르면 해당 운행 목록으로 갑니다.
- **휴대폰 연결(QR):** 차량 탭의 휴대폰 연결 카드에 QR이 뜹니다. 휴대폰 앱으로 찍으면 주소·연결 번호·인증키가 한 번에 들어갑니다. 번호는 5분 뒤 만료되고, 만료되면 QR도 사라집니다.
- **차량 관리 기한:** 정기검사·보험·리스 만기와 정비 주기는 30일 또는 1,000 km 안에 다가오면 홈에서 알려 줍니다. 정비소 카드 결제는 정비 이력으로도 남습니다.
- **사고·특이사항 원탭:** 홈 맨 아래의 사고 · 파손·긁힘 · 고장·경고 · 특이사항 중 하나를 누르면 시각·계기판·위치·운전자가 기록되고, 확인할 일 맨 앞에 대처 단계가 나옵니다. 잘못 눌렀다면 바로 실행 취소합니다.
- **운행 비서(로컬 규칙):** 검색 막대를 누르고 “주차비 4,500원 추가해줘”처럼 적으면 목적 기록·비용 추가·요약을 처리합니다. 이해한 내용을 먼저 보여 주고, ‘추가’나 ‘기록’을 눌러야 기록합니다. 차량 안의 한국어 문장 규칙으로 동작하며 네트워크를 쓰지 않습니다.
- **금액 표시:** 카드와 목록의 금액은 어느 화면에서나 숫자 뒤에 옅은 색 ‘원’이 붙는 한 가지 모양입니다. 금액 칸에 입력하면 천 단위 쉼표가 바로 들어가고, 연간 차량 비용은 ‘3,200만 원’처럼 한 번 더 읽어 줍니다. 범위를 넘으면 ‘100억 원까지 입력할 수 있어요’처럼 알려 주고 저장 버튼을 끕니다.
- **낮·밤 화면:** 화면 뒤의 하늘과 도시가 시계에 맞춰 낮·해 질 무렵·밤으로 바뀝니다. 카드와 글자의 색은 낮과 밤 두 가지이고, 해 질 무렵에는 밤 색을 씁니다. 자동 모드에서는 지하 주차장처럼 차량의 조도 센서가 어둡다고 알리면 밤 화면을 씁니다. 설정 › 기록 › 화면 밝기에서 자동·낮·밤을 고를 수 있고, 주행 중에는 바뀌지 않습니다.
- **배치와 움직임:** 넓은 창에서는 페이지 옆에 지금 열이 서서 사용자·예약·오늘 운행·이달 운행일지·차량을 늘 보여 주고, 해와 달은 인사말 오른쪽 하늘에 뜹니다. 도시는 화면 아래쪽에 서 있어, 내용이 짧은 화면에서도 아래가 비어 보이지 않습니다. 좁은 창에서는 머리줄이 두 줄이 되고, 지금 열의 내용은 머리줄과 홈으로 옮겨 갑니다. 이때는 해와 달이 없고 홈이 스크롤될 수 있습니다. 페이지는 옆으로 밀리며 바뀌고, 누른 카드와 탭은 살짝 가라앉습니다. 시스템의 애니메이션 축소 설정을 따릅니다.

주행 중에는 거리와 기록 상태만 남기고 버튼·입력·시트를 모두 닫습니다(Pleos 주행 제한).

## 휴대폰에서

휴대폰은 회사 차량을 다루는 원격 창구입니다. 휴대폰에서 바꾼 것은 차량에 ‘휴대폰’ 출처로 기록됩니다.

- **Google 로그인과 첫 설정:** Google 계정으로 시작하고, 처음 한 번 내 정보 → 법인차량 등록 → 직원 목록에서 나 고르기를 안내합니다. 다시 로그인하면 처음 설정을 건너뜁니다.
- **회사 차량 선택:** 머리줄의 차량 칩을 누르면 등록한 차량과 상태(사용 가능·예약 사용 중·운행 중)가 보이고, 눌러서 바로 전환합니다.
- **원격 확인:** 연결된 차량의 배터리·계기판, 관리 기한, 지금 운행 중인지를 홈에서 봅니다.
- **차량 예약(차량이 확정):** 예약 탭에서 빈 시간을 누르면 신청서가 채워집니다. 신청은 차량으로 가고, 차량이 시간과 겹침을 확인해 확정하거나 거절합니다.
- **운행·경비·현황:** 운행 목적을 정하고, 경비와 메모, 사고 현장 사진을 더하고, 이달 완성률과 차량 관리 현황을 확인합니다.
- **Excel:** 휴대폰에서도 같은 형식의 Excel을 만들 수 있습니다.
- **실시간 동기화:** 차량 화면의 QR을 찍어 연결합니다. 같은 Wi-Fi나 핫스팟 안에서 차량과 암호화 연결(TLS, 처음 연결 때 본 차량 인증서만 신뢰)로 이어지고, 변경이 바로 오갑니다. 받은 사진 속 QR이나 사설망 밖 주소가 든 QR은 주소를 보여 주고, 직접 **차량과 연결**을 눌러야 연결됩니다.
- **파일 사본:** 네트워크가 없을 때는 차량에서 저장한 운행파일(`.smlog`)을 가져와 사본으로 볼 수 있습니다.
- **낮·밤과 가로 모드:** 휴대폰도 같은 장면 규칙을 따르고, 상태 표시줄 아이콘까지 함께 바뀝니다. 설정의 ‘화면 분위기’에서 자동·낮·밤을 고를 수 있습니다. 가로로 돌리면 탭이 왼쪽 레일로, 태블릿에서는 카드가 한 줄에 넷으로 놓입니다.

## 어떻게 동작하나요

**하루의 운행**

1. **출발:** 기어를 P에서 바꾸면 차량이 기록을 시작합니다. 따로 누를 것은 없습니다.
2. **자동 기록:** 계기판 거리, 시각, 도착지 주소, 운전한 직원이 운행에 남습니다.
3. **주차 후 확인:** 정차하면 목적을 한 번 고릅니다. 이미 아는 목적지는 자동으로 채워집니다.
4. **카드 자동 반영:** 주유·충전·통행료·주차 결제가 해당 운행에 붙습니다. 확실하지 않은 건만 묻습니다.
5. **월 마감:** 남은 확인 건이 없으면 그 달을 마감합니다. 마감 뒤 고친 기록은 이력에 남습니다.
6. **Excel:** 운행기록부와 경비원장을 담은 Excel을 저장해 담당자가 검토합니다.

**차량 예약**

1. **예약 신청:** 휴대폰 예약 탭에서 시간·목적·목적지를 적어 보냅니다.
2. **차량 확정:** 차량이 직원·시간·겹침을 다시 확인해 확정하고, 지금 열의 예약 카드에 보여 줍니다.
3. **운전자 자동 전환:** 예약 시작 15분 전부터 차가 주차 중이면, 지금 운전하는 직원이 예약한 직원으로 한 번 바뀝니다. 그 뒤에 직접 고른 운전자는 그대로 남습니다. 예약한 직원이 그 시간에 시작한 운행은 예약 목적으로 기록됩니다.

## 기술

- **언어·UI:** Kotlin, Jetpack Compose Material3
- **차량 데이터:** Pleos Vehicle SDK와 AAOS Car API(기어, 계기판 거리, 배터리·충전 상태, 차종), 내비 장소 정보
- **동기화:** 차량 안의 로컬 TLS 동기화 서버(포트 9247), QR(ZXing)이나 6자리 번호로 연결
- **데이터 위치:** 외부 서버가 없습니다. 기록은 차량에 남고, 휴대폰은 사본과 명령만 주고받습니다.
- **Excel:** 기기에서 직접 `.xlsx`를 만듭니다.
- **장면:** 서울의 달별 대략적 일출·일몰 시각으로 낮·해 질 무렵·밤을 정하고(차량은 조도 센서도 함께 봅니다), 화면 색이 바뀔 때는 내용이 잠깐 사라졌다 새 색으로 돌아오는 페이드 스루로 넘어갑니다.

**알아 두실 점**

- Excel은 국세청 운행기록부 항목을 참고한 **검토 자료**입니다. 세무 신고나 국세청 전송, 영수증 발급은 하지 않습니다.
- Gleo 음성 동작(목적 기록·비용 추가·요약)은 설계와 처리 코드가 준비된 상태이며, **실제 음성 연결은 아직 동작하지 않습니다.** 승인과 발신자 검증 뒤에 켭니다.
- 카드 승인 알림을 받으려면 휴대폰에서 알림 접근을 허용해야 합니다.
