# SHAREMATE 개발용 연결 서버

차량 앱과 휴대폰 앱 한 쌍을 HTTPS로 연결하는 로컬 개발 서버입니다. 서버에는 차량 상태와 촬영 기록의 **메타데이터·해시·메모·AI 결과**를 저장합니다. 사용자가 요청한 AI 사진 확인은 축소 사진을 메모리에서 OpenAI로 전달하며 서버 디스크에 사진을 저장하지 않습니다. 영상은 전송하거나 분석하지 않습니다.

Python 3.10 이상이 필요합니다. 인증서 생성에는 `requirements.txt`의 cryptography를 사용하며, HTTP·TLS·저장은 Python 표준 라이브러리로 처리합니다.

```powershell
python -m pip install -r requirements.txt
python server.py
python -m unittest discover -v
```

기본 주소는 `https://127.0.0.1:8765`입니다. 실행하면 `.runtime` 아래에 아래 파일이 생깁니다.

- `car-link.txt`: 차량 앱용 연결 문자열
- `phone-link.txt`: 휴대폰 앱용 연결 문자열
- `config.private.json`: 서로 다른 차량·휴대폰 토큰
- `relay.crt`, `relay.key`: TLS 인증서와 비공개 키
- `relay-state.json`: 마지막 상태와 점검 메타데이터

연결 문자열 형식은 `HTTPS 주소|해당 기기 토큰|인증서 SHA-256 지문`입니다. 해당 파일의 내용을 각 앱의 연결 입력란에 붙여 넣습니다. **토큰·연결 문자열·비공개 키를 Git, APK, 시연 영상, 로그에 포함하지 마세요.** `.runtime/`은 소스 패키지와 버전 관리에서 제외해야 합니다. 토큰이나 지문을 stdout에 출력하지 않습니다.

안드로이드 에뮬레이터에서 호스트 PC에 연결할 때는 다음과 같이 시작할 수 있습니다.

```powershell
python server.py --advertise-url https://10.0.2.2:8765
```

실제 휴대폰은 같은 신뢰할 수 있는 로컬 네트워크에 연결하고, PC의 해당 로컬 IP를 명시합니다. 방화벽 설정은 사용자가 필요한 범위만 허용해야 합니다.

```powershell
python server.py --host 192.168.0.20 --advertise-url https://192.168.0.20:8765
```

예시 IP는 PC의 실제 로컬 IP로 바꾸세요. 최초 실행 때 지정한 호스트가 인증서에 들어갑니다. 주소를 바꾸어 인증서를 다시 만들거나 연결을 해제해야 하면 `--rotate-credentials`로 인증서와 **양쪽 토큰 모두** 교체하고, 각 앱에 새 연결 문자열을 입력합니다. 기존 대여 메타데이터는 이 옵션으로 삭제되지 않습니다. 계정이나 운영사 인증이 없는 개발 서버이므로 인터넷에 공개하지 마세요.

## 통신 계약

모든 API는 `Authorization: Bearer <role token>`을 요구합니다. POST는 `Content-Type: application/json`, 일반 메타데이터 최대 256 KiB, 사진 분석 최대 4,200,000 bytes입니다. NaN, Infinity, 중복 JSON 키, 알 수 없는 필드, 잘못된 범위·타입은 거부합니다.

| API | 허용 기기 | 기능 |
| --- | --- | --- |
| `GET /v1/state` | 차량·휴대폰 | 차량 상태와 현재 대여의 점검 요약 |
| `POST /v1/telemetry` | 차량 | 차량 상태·요금·대여 식별자 갱신 |
| `POST /v1/inspection` | 휴대폰 | 현재 대여와 일치하는 촬영 메타데이터·비교 후보·사고 메모 갱신 |
| `POST /v1/analyze` | 휴대폰 | 현재 촬영과 선택적 탑승 전 참조 사진의 AI 확인 |

GET 응답은 `{telemetry, inspection, receivedAt, telemetryReceivedAt}`입니다. `receivedAt`은 서버 현재 시각, `telemetryReceivedAt`은 마지막 차량 POST 수신 시각입니다. 차량의 원본 `sentAt`을 변경하지 않습니다. 앱은 오래된 측정치를 최신 차량 정보처럼 표시하면 안 됩니다. POST 성공은 `{ok:true, receivedAt}`이며 오류는 `{error:"코드"}`와 400·401·403·404·409·413·503 상태로 응답합니다.

각 연결은 한 대여에만 사용합니다. 활성 대여가 다른 ID로 바뀌는 요청은 409로 거부합니다. 차량에서 `sessionId:null`을 보내면 대여·점검 기록을 지우고 연결을 닫습니다. 닫힌 연결에서는 다음 이용을 게시할 수 없습니다. 다음 이용 전 서버를 `--rotate-credentials`로 재시작하고 새 연결 정보를 양쪽 기기에 입력하세요. 종료된 연결을 다시 열 때에만 닫힘 상태를 초기화하며, 이전 토큰은 새 서버에 접근할 수 없습니다.

종료 메시지는 반납 장소를 빈 문자열로, 시간·요금·요율·대여 주행거리를 null로 보내야 합니다. 다른 대여 ID의 휴대폰 업로드와 이미 저장한 시각보다 오래된 업데이트는 409로 거부합니다. 쓰기는 잠금과 원자적 파일 교체로 처리합니다.

점검 완료는 전·후 각 5개 슬롯을 기준으로 검증합니다. `FRONT/RIGHT/REAR/LEFT`는 `PHOTO`, `WALKAROUND`는 `VIDEO`이며, 전 점검 완료 없이 후 점검을 완료할 수 없습니다. 서버는 촬영 파일의 실체를 받지 않으므로 해시나 촬영 내용을 독립적으로 검증하지는 않습니다.

마지막 차량 POST에서 24시간이 지나면 다음 읽기/쓰기에서 저장된 대여·점검 데이터를 삭제하고 연결을 닫습니다. 서버를 정지한 동안 자동 삭제 작업은 실행되지 않습니다. 다음 이용에는 명시적인 자격 증명 회전이 필요합니다.

이 서버는 앱이 연결되어 있을 때 약 3초 간격으로 상태를 가져오는 개발용 연결을 위한 것입니다. 앱 종료·오프라인 상태의 푸시 알림, 운영사 자동 접수·과금·보험 판단, 다중 대여자 관리, 인터넷 운영 배포는 제공하지 않습니다. 촬영 비교 후보는 직접 확인을 돕는 표시이며 사고나 흠집을 확정하지 않습니다.

## AI 사진 확인

OpenAI Platform의 보안 키 설정 흐름에서 프로젝트 루트의 `.env.local` 저장을 승인한 뒤 서버를 다시 시작합니다. 서버는 `OPENAI_API_KEY` 환경 변수를 우선 읽고, 없으면 해당 파일의 같은 항목을 읽습니다. 키를 소스·APK·로그·소스 압축본에 넣지 않습니다. 키가 없어도 촬영·기기 내 비교·차량 동기화는 동작하고, AI 요청은 `ai_not_configured`로 실패합니다.

휴대폰 사진 확인 화면에서 **사진 전송 후 AI 확인 → 사진 전송·분석**을 누르면 현재 사진, 이용 후 촬영이면 같은 면의 탑승 전 사진을 전송합니다. JPEG 한 장당 최대 1,500,000 bytes, 긴 변 최대 1,280 px이며 앱이 EXIF를 제외해 재인코딩합니다. `gpt-4.1-mini`의 Responses API와 엄격한 JSON 형식을 사용합니다. `store:false`는 응답 저장을 요청하지 않는 설정이며 제공자의 다른 데이터 처리·보관 정책을 없애지 않습니다.

현재 연결의 대여 ID·기록 ID·방향·원본 해시가 저장된 촬영 요약과 일치해야 분석을 요청할 수 있습니다. 해시는 휴대폰 원본을 식별하며 서버가 원본 진위를 보증하지는 않습니다. 분석 중 이용이 종료되거나 기록이 바뀌면 결과를 적용하지 않습니다. 응답의 후보 수·유형·좌표·설명을 검사한 뒤 휴대폰이 원본과 연결해 저장하고 차량에 요약을 공유합니다. `REVIEW`는 직접 확인, `RETAKE`는 재촬영 권장, `NO_CANDIDATE`는 뚜렷한 후보를 찾지 못했다는 뜻이며 무손상 판정이 아닙니다.

동시에 한 건만 분석합니다. 같은 촬영 요청의 성공 응답은 메모리에 최대 32건 보관하며 이용 종료·만료 시 삭제합니다. 캐시는 서버 재시작 시 사라집니다. 응답을 받지 못한 요청을 재시작 후 다시 보내면 중복 비용이 생길 수 있으므로 자동 재시도는 하지 않습니다. API 이용료·한도는 해당 OpenAI 프로젝트에 적용됩니다.

사진 API의 성공 응답은 상태·설명·후보 좌표·모델·분석 시각·촬영 식별자입니다. 오류는 안전한 코드만 반환합니다. 키 미설정(503), 다른 분석 진행 중·API 이용 제한(429), API 인증·응답 오류(502), 잘못된 사진(400), 세션·촬영 불일치(409)를 구분합니다. 키·사진·제공자 원본 오류를 로그에 출력하지 않습니다.

자동 검증: `python -m unittest discover -v` — HTTPS 통합 17개와 모의 제공자 응답 11개입니다. 실제 API 응답 및 실제 손상 정확도 검증은 별도로 기록합니다. [검증결과](../검증결과.md)
